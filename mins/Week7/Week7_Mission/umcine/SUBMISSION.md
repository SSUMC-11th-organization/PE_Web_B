# 미션 캡처·제출 가이드

## 실행

이 폴더에서 `pnpm dev` 실행 후 터미널에 표시된 주소를 연다. 현재 검증용 프론트 주소는 `http://127.0.0.1:5178`이다.

## 필수 미션에 넣을 캡처

1. `/login`: 이메일·비밀번호를 입력한 화면. 비밀번호가 가려지고 로그인 버튼이 활성화된 상태를 캡처한다. 이번 주차는 로그인 API 미연결이다.
2. `/profile`: 기본 정보와 내 즐겨찾기가 함께 보이는 화면을 캡처한다.
3. `/profile/edit`: 닉네임을 바꾸고 연필 버튼으로 5MB 이하 이미지를 선택한다. 이미지 미리보기와 변경된 닉네임이 보이는 상태를 캡처한다. 이메일은 읽기 전용이다.
4. `변경사항 저장` 클릭 후 `/profile`: 변경된 닉네임과 이미지가 반영된 결과를 캡처한다. 2~4번 사이에는 새로고침하지 않는다. 프로필은 메모리 상태이므로 새로고침하면 초기화된다.

## 함께 기록하면 좋은 검증

- `/signup`에서 이메일 `test`, 닉네임 1자, 비밀번호 확인 불일치 등을 입력해 오류 메시지와 가입 버튼 비활성화를 캡처한다.
- 실제 회원 서버를 실행한 상태라면 중복 확인 완료와 가입 성공 결과도 추가할 수 있다. API 응답은 브라우저 개발자 도구 Network에서 확인한다. 토큰·비밀번호·실제 개인정보가 캡처에 포함되지 않게 한다.

## Notion 필수 미션 기록에 붙일 내용

아래 문장은 캡처한 동작을 직접 확인한 뒤 사용한다.

> Figma 디자인을 참고해 로그인, 내 정보 조회와 수정 화면을 구현했다. 로그인 폼의 입력값과 버튼 활성화 상태를 확인했고, 내 정보 수정에서 닉네임·프로필 이미지 변경 후 저장하면 조회 화면에 반영되는 것을 확인했다. 이메일은 읽기 전용이며, 로그인과 내 정보 API 연동은 다음 주차 범위로 남겼다.

핵심 코드로 `src/pages/auth/login-page.tsx`, `src/pages/profile/profile-edit-page.tsx`의 `handleSubmit`, `src/stores/profile-store.ts`를 짧게 첨부한다. 회원가입 실습도 기록하려면 `signup-page.tsx`의 `canSubmit`, 중복 확인 초기화와 API 요청 부분을 첨부한다.

핵심 키워드(인증·인가, JWT), 학습 후기와 스터디 사진은 본인이 작성·첨부한 뒤 Notion 공유 URL을 UMC에 제출한다.
